LHB UBO Verification System

คู่มืออบรมการใช้งานระบบ
สำหรับสอนจริง ทุกขั้นตอน พร้อมภาพประกอบ

เนื้อหาครบถ้วนจากเอกสารอบรม 2 ฉบับ ถ่ายภาพหน้าจอจากระบบจริงทุกฟังก์ชัน เลือกคู่มือตามกลุ่มผู้เรียนได้ทันที

2 คู่มือ 62 ภาพหน้าจอจริง 14 บทเรียน TH พร้อมสอน
DOCUMENT 1 · AML / BU

คู่มือสำหรับทีม AML และ Business Unit

การใช้งานทุกฟังก์ชันของระบบ ตั้งแต่การเข้าสู่ระบบ การค้นหาและวิเคราะห์ UBO ผลการวิเคราะห์และ Ownership Graph การพิมพ์รายงาน PDF ประวัติการค้นหา Activity Log และ System Log ตลอดจนการตั้งค่าระบบ Configuration, General Settings, Waiting Page Setting และ API Configuration

7 บทเรียน 31 ภาพประกอบ ไม่ครอบคลุมการจัดการผู้ใช้และสิทธิ์
เปิดคู่มือ AML / BU → DOCUMENT 2 · ITSD

คู่มือสำหรับทีม ITSD และหน่วยงานที่เกี่ยวข้อง

วิธีการใช้งานทั่วไปพร้อมภาพประกอบ ภาพรวมระบบสิทธิ์ 4 ชั้น User → Group → Role → Permission วิธีสร้าง Role วิธีสร้าง User ทั้งแบบอัตโนมัติและอัปโหลด CSV วิธีสร้างและจัดการ User Group รวมถึง Waiting Queue การมอบหมายกลุ่ม และขั้นตอนตรวจสอบยืนยันผล

7 บทเรียน 31 ภาพประกอบ Step by Step ทุกขั้นตอน
เปิดคู่มือ ITSD →

วิธีใช้เว็บไซต์นี้สำหรับการอบรม

  1. เลือกคู่มือตามกลุ่มผู้เรียน จากการ์ดด้านบน
  2. ใช้สารบัญทางด้านซ้ายกระโดดไปบทที่ต้องการสอน รายการที่ไฮไลต์คือบทที่กำลังแสดงอยู่
  3. คลิกภาพหน้าจอเพื่อขยายเต็มจอ ใช้ลูกศร ← → เปลี่ยนภาพ และ Esc เพื่อปิด
  4. ปุ่ม พิมพ์หน้านี้ ด้านบนขวา ใช้ปรินต์แจกเป็นชีตให้ผู้เรียนได้
  5. บนมือถือหรือแท็บเล็ต กดปุ่ม ☰ สารบัญ เพื่อเปิดรายการบทเรียน
